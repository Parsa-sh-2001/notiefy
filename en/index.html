Don't want to manually handle API requests? Use the NotieFy library and interact with the service directly from your application.

Frequently asked questions.

A few things you might want to know.

What is NotieFy?

NotieFy is a notification service that allows applications to send notifications through an API and developer library.

Do I need to build my own notification system?

Nope. That's the point. Your application sends a request to NotieFy and NotieFy handles the notification delivery.

What notification methods are supported?

Email notifications are supported initially, with additional notification channels planned for the future.

Can I use NotieFy with my own application?

Yes. You can integrate NotieFy using the API or the NotieFy library.

Is there an API?

Yes. NotieFy provides an API specifically designed for application-to-NotieFy communication.
